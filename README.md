# prompt

Public page with a ready-to-copy AI prompt for building a personal context file.
Used in the evisions lecture at FSV UK (QR code on the slide "Jak dát AI kontext").

- Page: https://evisions-advertising.github.io/prompt/
- Source of the prompt text and the page template: the evisions `ai-fsv26` lecture project
  (`assets/qr/kontext-prompt.txt`, `prompt-page/`). Rebuild there, then copy `index.html` here.
- CI: `scripts/check_page.py` checks the HTML parses, the prompt is present and the buttons are wired.

No client data, no secrets. Public on purpose (GitHub Pages).
